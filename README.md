# My Favorite Series: Stranger Things

## About the Series
**Stranger Things** is a *sci-fi horror* series set in the 1980s.
It follows a group of kids in a small town called Hawkins.

## Main Characters
- Eleven
- Mike Wheeler
- Dustin Henderson
